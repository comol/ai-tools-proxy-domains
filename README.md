# AI tools proxy domains

Списки хостов и масок Proxifier, чтобы гонять Cursor, Codex, Claude и соседние AI-сервисы через прокси **без полного VPN на всю машину**.

Два варианта:

1. **Точные домены** — узкий split-tunnel. Меньше побочек, легче дырки, если вендор завёл новый поддомен.
2. **Маски Proxifier** — «лучше перебдеть». Ловит служебные CDN/телеметрию, но `*google*`, `*github*`, `*microsoft.com*`, `*cloudflare*` и `*windowsupdate*` заворачивают уже почти всё подряд.

Схема, которая у автора масок работает без VPS:

- локальный прокси (у него это `127.0.0.1:8090`);
- Proxifier: AI-трафик в цепочку, localhost/Docker/системное — Direct;
- брандмауэр: исходящие у Cursor/Codex/VS Code/Antigravity **блокируются напрямую**, чтобы процесс не ушёл мимо прокси.

Оплата Cursor/Codex через эту схему у автора проходит. Адреса собирались агентом из открытых источников — **на полноту и точность никто не подписывается**. Дополняйте пулреквестами.
